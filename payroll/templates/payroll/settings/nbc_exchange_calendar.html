{% load i18n %} {% comment %} "Exchange Rate Calendar" of the Settings -> General "Exchange Rate" card. Renders a clean 7-column month grid (see payroll.views.tax_views._build_exchange_rate_calendar) that shows the USD -> KHR rate stored for every day, the automatic resolution of the 15th (a weekend or public-holiday 15th rolls back to the closest working day before it) and the day whose rate is currently applied to the payroll calculation. Cambodian calendar styling: the week starts on Sunday, Saturdays, Sundays and public holidays (the Cambodian holiday table of payroll.methods.cambodia_calendar merged with Settings -> Holidays) show their day number in red and print the holiday name underneath. The month navigation and the "set the rate of a day" form refresh only this fragment with HTMX (payroll.views.tax_views.settings_exchange_rate_calendar), so browsing the calendar never reloads the whole System Preferences page. {% endcomment %}
