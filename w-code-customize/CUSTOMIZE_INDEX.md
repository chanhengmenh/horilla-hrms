How to use this folder
----------------------
1. `w-code-customize\<path>` mirrors the real project path exactly.
   Example: `w-code-customize\payroll\methods\tax_calc.py` is the
   customized copy of `payroll\methods\tax_calc.py` in the project root.
2. After updating the Horilla system, check CUSTOMIZE_INDEX.md (this file)
   first: every file listed here carries custom changes and must be
   re-checked / re-applied to the updated code.
3. To restore a customized file over a freshly updated one, copy it from
   this folder back to the same relative path in the project root.
4. `[ADDED]` files are brand new (did not exist in the original) - if a
   system update does not include them, copy them over as-is.
5. To refresh this snapshot after making more custom changes, run:

   .venv\Scripts\python.exe _compare_snapshot.py

   (run from the project root; edit ORIGINAL inside the script if the
   baseline must change). `.env` and database files are never snapshotted.
